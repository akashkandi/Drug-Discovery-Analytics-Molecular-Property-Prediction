# Data Dictionary — Drug Discovery ML Pipeline

## 1. Raw Datasets

### BBBP.csv — Blood-Brain Barrier Permeability
Source: MoleculeNet / DeepChem (Wu et al., 2018)
URL: https://deepchemdata.s3-us-west-1.amazonaws.com/datasets/BBBP.csv

| Column | Type   | Description |
|--------|--------|-------------|
| num    | int    | Row index |
| name   | string | Molecule name or identifier |
| p_np   | int    | **Label**: 1 = permeable (crosses BBB), 0 = non-permeable |
| smiles | string | SMILES string encoding molecular structure |

**Task:** Binary classification — predict BBB permeability from structure.

### delaney-processed.csv — ESOL Aqueous Solubility
Source: Delaney (2004), curated by DeepChem
URL: https://deepchemdata.s3-us-west-1.amazonaws.com/datasets/delaney-processed.csv

| Column | Type   | Description |
|--------|--------|-------------|
| Compound ID | string | Compound name |
| measured log solubility in mols per litre | float | **Target**: experimental LogS (log10 mol/L) |
| smiles | string | SMILES string |
| (additional columns) | — | Various physicochemical properties (not used) |

**Task:** Regression — predict aqueous solubility (LogS) from structure.

## 2. Feature Matrix — features_bbbp.csv

Generated by `src/feature_engineering.py`.
Shape: N_valid_molecules × 2058 columns (2048 fingerprint bits + 9 descriptors + metadata).

### Morgan Fingerprint Columns (ECFP4)

| Column Pattern | Type | Description |
|----------------|------|-------------|
| fp_0 … fp_2047 | int (0/1) | Morgan fingerprint bit vector. Radius=2 (ECFP4), 2048 bits. Each bit encodes the presence/absence of a particular circular substructure within 2 hops from any atom. |

**Algorithm:** `rdkit.Chem.AllChem.GetMorganFingerprintAsBitVect(mol, radius=2, nBits=2048)`

### Molecular Descriptor Columns

| Column | Unit | Range (typical) | Description |
|--------|------|-----------------|-------------|
| MolWt | Da | 50 – 900 | Molecular weight (average isotopic mass). Lipinski: ≤ 500 Da for oral bioavailability. |
| MolLogP | dimensionless | −3 – 8 | Wildman–Crippen estimated octanol/water partition coefficient. Measure of lipophilicity. Lipinski: ≤ 5. Higher LogP → more lipophilic → better membrane permeability (up to a limit). |
| TPSA | Å² | 0 – 200 | Topological Polar Surface Area — sum of surface contributions of polar atoms (N, O, S and attached H). TPSA < 90 Å² is associated with good BBB penetration. |
| NumHDonors | count | 0 – 10 | Number of hydrogen bond donors (O–H and N–H groups). Lipinski: ≤ 5. |
| NumHAcceptors | count | 0 – 15 | Number of hydrogen bond acceptors (O and N atoms). Lipinski: ≤ 10. |
| NumRotatableBonds | count | 0 – 20 | Number of rotatable bonds (excluding rings, terminal bonds). Relates to molecular flexibility and oral bioavailability. |
| RingCount | count | 0 – 8 | Total number of rings in the molecule. |
| NumAromaticRings | count | 0 – 6 | Number of aromatic rings. High aromaticity can improve metabolic stability. |
| FractionCSP3 | fraction (0–1) | 0 – 1 | Fraction of sp³ carbon atoms out of total carbons. Higher values → "more 3-dimensional" → often better solubility. |

### Metadata Columns

| Column | Type | Description |
|--------|------|-------------|
| name   | string | Molecule name (from BBBP dataset) |
| smiles | string | SMILES string used for feature generation |
| p_np   | int (0/1) | BBB permeability label (target variable) |

## 4. Invalid SMILES Report — invalid_smiles_report.txt

Lists SMILES strings that could not be parsed by RDKit's `Chem.MolFromSmiles()`.
These molecules are excluded from all analyses.

Common causes of invalid SMILES:
- Malformed ring-closure notation
- Unsupported element symbols
- Valence errors
- Empty strings or non-SMILES text in the column

---

## 5. Lipinski Rule of 5 Reference

| Property | Threshold | Rationale |
|----------|-----------|-----------|
| MolWt | ≤ 500 Da | Membrane permeability decreases with size |
| MolLogP | ≤ 5 | Too lipophilic → poor aqueous solubility |
| NumHDonors | ≤ 5 | H-bond donors slow membrane crossing |
| NumHAcceptors | ≤ 10 | Excess H-bond acceptors → low permeability |

Note: The BBB has stricter requirements than general oral bioavailability —
CNS drugs typically need TPSA < 90 Å² and MW < 450 Da.
